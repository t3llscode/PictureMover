# PictureMover
This is a script to automatically get your photos and videos of your SD Cards, external Harddrives, or any other storage medium, as well as folders on your device, while also sorting the files by date.

## Versions

The `PictureMover.py` file is for Windows, while `PictureMoverMac.py` is for devices with macOS. Due to the systems commands for copying and replacing, there are seperate versions.

## Input

Specify the volume / directory you want to export from with the `sdCard` or `sdCardName` variables.

## Output

Set the output of videos via the `vidPath` variable, same for phtotos with `picPath`. If you want to ex- or include certain filetypes, you can do this using the `...Suffices` variables.
